### Fedi Mdaini

Data Scientist working on ML engineering: taking models from a notebook to something that runs, is tested,
and can be measured. Lately that means LLM agents, retrieval systems and MLOps pipelines.

**Selected work**

- [**builder-agent**](https://github.com/fedimdaini/builder-agent): an agent that turns a Python ML repo into a
  working pipeline (Docker, Makefile, CI, MLflow), verifies it in a sandbox and repairs build failures with a
  local LLM and a memory of past fixes. Evaluated over 252 sandbox runs with a protocol fixed before the
  first run.
- [**tennessee-policy-rag**](https://github.com/fedimdaini/tennessee-policy-rag): question answering over state
  policy documents with two-stage retrieval (bi-encoder, then cross-encoder reranking), grounded answers with
  refusals, and a custom LLM-as-judge evaluation with a held-out test.
- [**ml-pipeline-refactor**](https://github.com/fedimdaini/ml-pipeline-refactor): a monolithic Flask ML app
  refactored into a tested, modular pipeline with MLflow tracking and Docker.
- [**telco-customer-churn**](https://github.com/fedimdaini/telco-customer-churn): churn prediction with
  XGBoost and SHAP, a cost-based decision threshold, and a FastAPI + Streamlit service.
